### Featured

- 🔬 **[ServidorOPCUA-EPICS](https://github.com/joaquin-salas/ServidorOPCUA-EPICS)**: my bachelor's thesis for [IFMIF-DONES](https://ifmif-dones.es/), the particle accelerator facility being built in Granada. I took it over when it collapsed above 100 process variables and scaled it to **55,000 concurrent variables**, with an event-driven core and batched asynchronous discovery (10,000 variables in 2.5 s, before: 1,000 in 10 s).
